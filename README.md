# 📋 TaskFlow | Real-Time Collaborative Workspace

A real-time project management tool designed for seamless team collaboration. Built with React, Node.js, Socket.io, Redis, Docker, and MongoDB.

## 🚀 Tech Stack
* **Frontend:** React
* **Backend:** Node.js, Socket.io
* **Database:** MongoDB
* **Caching:** Redis
* **DevOps:** Docker

## ✨ Key Features
* **Real-Time Updates:** Instant synchronization of task boards across all clients.
* **Drag-and-Drop Boards:** Intuitive UI for moving tasks between columns.
* **Redis Caching:** High-performance data retrieval and reduced database load.
* **Containerized:** Dockerized for consistent deployment environments.

## ⚙️ Setup Instructions
1. Clone the repository.
2. Run `docker-compose up` to start the Redis and MongoDB containers.
3. Install dependencies using `npm install`.
4. Start the backend and frontend servers.
